## 學習重點

- **Procreate**：手勢操作、圖層、畫筆與匯出
- **AI 圖像生成**：豆包、Qwen、Nano Bananar 等平台入門
- **理論基礎**：LLM、Tokenization、潛在空間（Latent Space）
- **提示詞工程**：主體、風格、環境、光線、視角
- **倫理反思**：AI 偏見、版權及社工應用態度
